# Future features

Specced but not built. One file per feature, named `FEATURE-NAME.md`. Read the
file before starting the feature; write one here (not inline in another doc) when
a feature is scoped but deferred.

Each file covers:

- **Problem**: what it fixes or enables, and for whom.
- **Scope**: what is in and what is explicitly out.
- **Affected areas**: renderer (GL / GLES), platform, engine, game, data, build/CI.
- **Approach**: the plan, and alternatives rejected with the reason.
- **Verification**: how we will know it works, on which platforms.
- **Open questions.**

When a feature is built, delete its file here and record it in `planning/PROGRESS.md`.

`NETWORKING.md`, `MOD-COMPAT.md`, `GPU-BENCHMARK.md`, `PI-RENDER-PERF.md`.
